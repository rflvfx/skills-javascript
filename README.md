# skills-javascript

**Fundamentos e padrões de JavaScript moderno** — de closures e event loop a async/await.

</div>

## 📋 Sobre

Coleção de estudos e utilitários em JavaScript puro, cobrindo desde os fundamentos da linguagem até padrões usados no dia a dia de desenvolvimento.

## 📂 Conteúdo

- `index.js` / `index.test.js` — exemplos base com testes
- `examples/` — async patterns (`async.js`), transformações de arrays (`arrays.js`)
- `utils/` — biblioteca de helpers: `strings.js`, `timing.js`, `objects.js`
- `docs/` — notas por tópico: closures, prototypes, event loop, promises...

## 🚀 Quick start

```bash
node index.js
npm test
```
